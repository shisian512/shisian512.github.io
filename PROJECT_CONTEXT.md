# Project purpose

Interactive portfolio for Tan Shi Sian, highlighting Site Reliability Engineering, DevOps, platform engineering, MLOps, and AI infrastructure.

# Architecture

- `src/App.jsx`: portfolio content and interactive sections.
- `src/styles.css`: Tailwind entry plus responsive visual system.
- `src/main.jsx`: React application entry.
- `index.html`: SEO metadata and JSON-LD.
- `public/bio-photo.jpg`: profile image.
- `.github/workflows/deploy.yml`: GitHub Pages build and deployment.

# Development

- React 18 and Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React

Run `npm run dev` locally and `npm run build` for production.
